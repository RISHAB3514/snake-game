# 🐍 Snake Game

A classic Snake Game built with smooth controls, score tracking, and clean game logic.

## 🚀 Features
- 🎮 Simple and interactive gameplay
- 📈 Score tracking system
- ⚡ Increasing difficulty as score grows
- 💥 Collision detection (walls & self)
- 🎯 Smooth controls

## 🛠️ Tech Stack
- Language: (JavaScript)

## 🎮 Controls
